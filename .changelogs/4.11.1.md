# Qz-UILib 4.11.1

**本版要点**

- **内部开发工具整包移出发布产物**：`internal.devtools` 此前只排除了 `headless` 子包，其余 77 个条目（scene 测试场地、磨玻璃实验室、网络自检端点、开发环境完整命令）随 4.11.0 发布 jar 出厂。本版把打包边界统一到整包，门禁由 `verifyHeadlessNotPackaged` 扩为 `verifyDevToolsNotPackaged`。
- **命令入口按环境分档**：发布产物内只保留玩家通道 `/qzuilib <modernconfig|chatmd on|off|status>`；以 `test` / `glass` 打开开发设施的用法只在开发环境存在（`runClient` 与 headless 出图用法不变）。玩家侧的配置页入口另有 Mod 列表配置按钮（`ModConfigGui`）。
- **生产日志写法收敛**：配置事件总线与可变配置的监听器异常隔离由 `e.printStackTrace()` 改为 log4j `LOG.error`（原先绕过日志系统直写 stderr，无前缀、不受级别控制、无法过滤归档）；启动期 preInit 时序插桩由 INFO 降为 debug。

## 兼容性与升级动作

- **公共 API 面：本版无新增、无删除、无签名变更**——`internal.devtools` 与新增的 `client.command` 同属 🔒 内部面，不在兼容承诺内。故按《发布流程》§1，本版取**修订号** 4.11.1，不走预发布通道（预发布通道留给 minor 级的公共能力新增）。
- **FML 远端范围**：`MyMod.acceptableRemoteVersions` 保持 `[4.11.0,4.12.0)`——补丁版本沿用既有已承诺区间（同 4.9.1 先例），**4.11.x 内部相互接受、可混用**；与 4.10.x 及更早版本仍不承诺混用。
- **升级动作**：直接替换 jar，无需改配置或迁移数据。若此前依赖发布版里的 `/qzuilib test` 或 `/qzuilib glass` 打开测试场地，请改用开发环境——这两个子命令的实现随开发设施一并移出产物；发布产物内 `/qzuilib modernconfig` 与 `chatmd on|off|status`（聊天接管逃生舱）不受影响。
- **网络协议**：本批无协议相关改动，通道注册表与线格式不变。
